# Bank Transaction System

A Node.js backend foundation for a bank transaction system, built with Express and Mongoose.

## Current stack

- Node.js
- Express 5
- Mongoose 9
- dotenv

## Getting started

### Prerequisites

- Node.js 18 or later
- A MongoDB instance for future database-backed features

### Install dependencies

```bash
npm install
```

### Environment configuration

Create a `.env` file in the project root when application configuration is added. Do not commit credentials or connection strings.

### Run

The application entry point is configured as `index.js`. Add the server implementation there, then run:

```bash
node index.js
```
